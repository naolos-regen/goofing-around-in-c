# sorting algorithms explained for mahself

## Rules are simple (or are they)
rearranging arrays of items where each item contains a key. the objective is to rearrange the items in such that their keys are in either ascending or descending order. for that most of the sorting algorithms must have function pointers that compare each generic data with eachother. 

- if we want to swap we call default swap that we must implement ourselves. 
- if we need less eq or bigger as functions we also can precreate them ourselves.
- if wanted or needed create tests beforehand. they are mostly abstract (because they look the same), however you test each datatype, maximum and minimum limits, in order to see if there is no undefined side-effect.
